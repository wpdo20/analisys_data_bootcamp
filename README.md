🧠 Project Overview
This project presents a data analysis performed using dashboards and datasets to identify where the company achieves higher profits and stronger sales performance.

⚙️ Tools Used
Python (Pandas, Matplotlib, Seaborn)

Excel for initial data exploration

Power BI for dashboard visualization

📊 Key Insights
Highlighted regions with the highest revenue growth

Identified product categories with the best sales margins

Provided recommendations for improving low-performing areas

🚀 Purpose
This analysis was developed as part of a bootcamp project proposal by DIO (Digital Innovation One) to strengthen data analytics skills and dashboard creation techniques.
